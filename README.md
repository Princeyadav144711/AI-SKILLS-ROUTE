# AI SKILLS ROUTE

AI Skills Route is an AI-powered career guidance
web application developed using Python Flask.

## Features
- User Registration and Login
- Student Skill Assessment
- AI-Based Career Recommendations
- Skill Gap Analysis
- Personalized Learning Roadmap
- Learning Resources
- Project Recommendations
- Gemini AI Career Advisor

## Technologies Used
- Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript
- Google Gemini API

## Installation

1. Clone the repository.
2. Create a virtual environment.
3. Install requirements.
4. Configure Gemini API key in .env.
5. Run python app.py.
